# Projeto de Análise de Vendas com Python e Pandas

## Objetivo
Este projeto analisa dados de vendas, realiza limpeza de dados e gera relatórios automatizados.

## Tecnologias utilizadas
- Python
- Pandas
- Excel
- Matplotlib

## Funcionalidades
- Limpeza de dados
- Análise de vendas por cliente
- Análise de vendas por cidade
- Criação de gráficos
- Exportação de relatórios
